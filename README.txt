PACCHETTO PRONTO PER LA PUBBLICAZIONE

Contenuto:
- index.html
- cartella img/

Istruzioni:
1. Caricare online tutto il contenuto di questa cartella, non solo index.html.
2. La cartella img deve restare allo stesso livello di index.html.
3. Dopo il caricamento, il sito si aprira automaticamente dall'indirizzo della cartella, perche il file principale si chiama index.html.
4. Per modifiche future, sostituire index.html e/o le immagini nella cartella img mantenendo gli stessi nomi file, quando possibile.

Nota:
La sezione Mappa rapida contiene ancora il segnaposto per il link Google Maps che verra fornito in seguito.
